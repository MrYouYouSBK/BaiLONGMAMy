# GAI AI 3.2.0

GAI AI 3.2 brings the desktop assistant under one GAI identity and makes voice, local AI, updates, sharing and timelines reliable enough for daily use.

- Verified automatic updates on Windows and community macOS builds, with SHA-256 validation and rollback-safe replacement.
- Always-on local wake listening for “GAI AI” / “Hey GAI”, optional double-clap sound wake, and an unlimited conversation period.
- Simultaneous Chinese, English and Bahasa Melayu recognition by default, with rolling native recognition for long sessions.
- Screen sharing is off by default and controlled by an explicit UI toggle; a current-screen capture can be attached to chat.
- Apple Silicon and M5-aware local inference settings, Metal/MLX discovery, and recommended local-model activation.
- GAI Offline Super, local Ollama / LM Studio / MLX, ChatGPT/Codex login and custom endpoints can be selected from one control center.
- Task timelines create desktop reminders, automatically perform already-authorized safe steps, verify results and follow up when input is needed.
- Warm chat greetings, optional startup music, easier Google account selection, refreshed GAI AI artwork and voice reliability fixes.

The release includes Windows x64 and macOS x64/arm64 installers plus `SHA256SUMS.txt` for independent verification.
